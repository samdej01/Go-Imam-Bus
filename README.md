# 🚌 Go Imam 

**Go Imam Bus** is a web-based application designed to help users track and manage bus transportation routes at Al Imam Mohammad Ibn Saud Islamic University campus.

The project focuses on providing a simple and accessible interface for viewing bus information, supporting better transportation planning for students and users.

---

## 📍 Project Overview

Go Imam Bus aims to simplify campus transportation by offering an organized way to view bus routes and related information.  
The application demonstrates practical web development skills while addressing a real-world university use case.

---

## ✨ Features

- View available bus routes
- Access transportation-related information
- Simple and user-friendly interface
- Web-based access from any device

---

## 🛠️ Tech Stack

### Frontend (App UI)
- Softr (template-based web app builder)
- HTML (content/customization)

### Database
- Airtable (data storage and management)

### Backend
- No custom backend code (handled through Softr + Airtable integration)

---

## 🧠 What This Project Demonstrates

- Building and customizing a web app using a no-code platform
- Front-end-focused development using templates and structured UI blocks
- Database-driven apps using Airtable as a data source
- Real-world problem solving for a university use case
